01

Clinka Clinic Manager

A mobile app that replaced 4 tools with one, for a real psychologist's daily practice.

The Problem

A psychologist running a solo private clinic was juggling Google Calendar for scheduling, handwritten notes for payment tracking, and mental math for monthly revenue. Cancellation patterns were invisible. Payment debts accumulated silently. Rescheduling a single session meant fighting with Google's recurring events.

The Solution

A Hebrew-native Android app that handles the full daily workflow: add patients with recurring schedules, confirm sessions with one tap, track payments and debts automatically, get push notifications before sessions, and sync everything to Google Calendar.

PM Thinking

I wrote the full PRD from scratch based on real user conversations. Prioritized ruthlessly: v1 shipped with the 6 highest-impact features, deferring multi-user support and clinical notes. Designed the data model, tested with the actual user, iterated on real feedback, and shipped the APK.

The Problem

Neuropsychologists assessing children use standardized test batteries with hundreds of tasks across 5 different protocols. The entire workflow was Excel-based: manually entering Z-scores, color-coding cells by hand, creating charts from scratch, and copy-pasting everything into Word documents. Each report took hours. Errors were common and hard to catch.

The Solution

A full-stack web app with 5 pre-configured assessment protocols and around 300 tasks. Psychologists select a protocol, enter Z-scores with auto-save, and instantly see color-coded bar charts (green/yellow/red). One click generates a professional Word document with charts, tables, and optional password protection - or exports directly to Google Sheets.

PM Thinking

Designed the data model for 5 clinical protocols with a snapshot pattern that lets each assessment work independently. Defined the 7-level Z-score categorization system with Hebrew labels. Prioritized auto-save and drag-and-drop reordering based on user workflow observation. Wrote the complete 2,900-line PRD and interactive HTML prototype before writing a single line of code.
